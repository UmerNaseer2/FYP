                            Literature Review
Schema Matching
Rahm & Bernstein (2001) show that effective schema matching must combine name,
structural, and semantic signals, informing the weighted scoring algorithm in this tool.
Melnik et al. (2002) show that entity similarity propagates to structurally related
neighbours, motivating the column-context weighting in the matching phase.

Schema Evolution
Brahmia et al. (2024) find that automated migration tooling remains fragmented and
largely requires manual script authoring: the gap this project addresses.
Hu et al. (2022) show that properly sequenced schema changes can be applied with
near-zero downtime, motivating the version-gapped execution model in the apply
pipeline.

Existing Tools: Gap Analysis
Flyway and Liquibase manage script execution and ordering, but neither detects drift nor
generates scripts automatically. This project fills that upstream gap.

System Architecture
The tool introspects two PostgreSQL instances via information_schema and pg_catalog,
runs weighted similarity matching, computes a colour-coded diff, generates a migration
script, pushes it to GitHub, and provides a pull-and-apply pipeline for the target database.

                                                                                                                                                Conclusions
                                                                                               This tool automates the full schema drift lifecycle from detection to deployment, replacing
                                                                                               a fragile manual process with a structured, auditable workflow. The similarity algorithm
                                                                                               handles renamed entities and constraint drift.
                                                                                               GitHub integration provides a versioned record of all migration scripts. SemVer auto-
                                                                                               bumping makes correct versioning the default, not the exception.
