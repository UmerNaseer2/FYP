Demo Walkthrough — Step by Step
1
Push GitHub scripts. In the app's Scripts page, use "Push to GitHub" to push the 4 SQL files from demo/github-scripts/ into staging/user_schema/ and production/user_schema/. (Or paste the SQL directly into GitHub via the web UI.)
2
Set up the database. In pgAdmin, run demo-setup.sql. This creates both schemas and pre-fills script_patch — staging at v1.0.0, production at v4.0.0.
3
Demo: staging needs updates. Open the Deploy panel. Select your connection → staging schema → user_schema group → Click "Check DB". The app shows current: v1.0.0, pending: v2.0.0, v3.0.0, v4.0.0. Use the target version picker to deploy to v3.0.0 first.
4
Deploy incrementally. After deploying to v3.0.0, click "Check DB" again. Only v4.0.0 is pending. Select it and deploy — "all scripts applied" banner appears.
5
Demo: production is up to date. Switch schema to production → "Check DB". The app shows current: v4.0.0, pending: none. "Up to date" message appears.
6
Reset for another run. In pgAdmin, run demo-reset.sql (drops both schemas), then re-run demo-setup.sql to restore the starting state.
